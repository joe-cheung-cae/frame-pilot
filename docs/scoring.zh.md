# 评分

> 语言：[English](scoring.md) | **中文**

MVP 评分模型是确定性的、可解释的。

## 技术分数

- 锐度：对亮度应用简单拉普拉斯核后的方差。
- 模糊风险：归一化锐度的倒数。
- 曝光：平均亮度与中灰的距离。
- 对比度：归一化的亮度标准差。
- 噪声风险：高频亮度偏差估计。
- 美感：在加入专用本地模型之前，取曝光与对比度的平均值。
- 实验性人脸与眼睛分数：轻量本地启发式信号，不是专业人脸检测模型。

## 人脸与眼睛启发式

MVP 不捆绑训练好的人脸检测器、关键点检测器或眼睛状态模型。人脸与眼睛评分实现为小型确定性 NumPy 启发式，以便在保持本地优先、依赖尽量少的前提下，向工作流暴露面向人像的排序信号。

该启发式：

1. 用 RGB 通道阈值构建较宽的肤色掩膜。
2. 候选肤色区域过少的图像会被拒绝。
3. 检查候选包围盒的形状、面积和填充比，以估计 `face_presence`。
4. 用与全局锐度相同的简单拉普拉斯方差，在候选脸部区域上测量 `face_sharpness_score`。
5. 根据候选脸部框中上区域的暗部细节量，估计 `eye_open_confidence`。
6. 将脸部锐度、睁眼置信度和全局锐度组合成 `face_quality_score`。

这些实验性信号可用作弱的 MVP 排序提示。它们可能漏检人脸，尤其是在异常光照、肤色、侧面、遮挡、极小人脸、重度调色、灰度图或非人像场景中。肤色物体也可能产生误报。它们不应被视为身份识别、生物特征分析，或可靠的专业肖像质量模型。

## 组内排序

基线组内排序公式为：

```text
final_score =
    0.30 * sharpness_score
  + 0.20 * exposure_score
  + 0.15 * contrast_score
  + 0.10 * noise_quality_score
  + 0.15 * experimental_face_quality_score
  + 0.10 * aesthetic_score
  - 0.10 * duplicate_penalty
```

`noise_quality_score` 是本地噪声风险的倒数。重复组中排名最高的照片获得 Pick 推荐，同组其他照片根据与最佳分数的差距获得 Maybe 或 Reject。非最高的重复候选仅在落后最佳分数超过 `0.10` 时才获得 Reject；更接近的候选获得 Maybe。单图组仅在确定性分数至少为 `0.55` 时获得 Pick；较弱的单图获得 Maybe，以便用户手工复核。用户决定始终覆盖推荐。

排序会按每张照片的上下文做小幅确定性权重调整：

- 检测到实验性人脸信号的类人像照片，将 `experimental_face_quality_score` 提高到 `0.20`，并略微降低锐度、曝光和对比度权重。
- 无人脸信号的类风景照片，提高锐度、曝光和对比度权重，同时降低实验性人脸信号权重。

每个已处理组还会存储确定性 JSON `score_summary`。单图组置信度低，因为没有可比较的相近替代。重复组在最佳照片领先下一候选至少 `0.15` 时为高置信度，至少 `0.05` 时为中等置信度，低于该差距为低置信度。
