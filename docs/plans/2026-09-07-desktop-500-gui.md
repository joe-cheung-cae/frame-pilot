## 6. Harness (`packaging/scripts/desktop-500-gui.sh`) — 开发 Slice 2+, not 评审

`set -euo pipefail`. Self-contained launch/discovery (copy the needed attach/`xattr`/port/`lsof`/quit logic; do **not** call `macos-dmg-gui-smoke.sh`).

### 6.1 Modes

| Invocation | Dataset | Pass ticks §2.2? |
| ---------- | ------- | ---------------- |
| `--probe` | **1** JPEG 3000×2000 q88 | **No** |
| `--count 500` | **500** JPEG 3000×2000 q88 | Only if **both** OS 500 pass |

`--probe` uses the **same** Path B runner through milestone `done` (`naturalWidth > 0`), then GUI quit. There is **no idle-only mode**. Do **not** quit after `idle` while import/process is running (live quit dialog is a human gate). If the step times out with a running job: `POST .../jobs/{id}/cancel`, wait up to 10s, then GUI quit; still exit 1.

Fail-fast: no `idle` JSONL **90s** after `/health` 200 → exit 1 (SPA never booted). Dump process list + sidecar.log tail.

Exit: **0** pass; **1** fail; **2** skip-not-pass (local Linux/WSL2 only).

### 6.2 Dataset (Windows-safe)

Do **not** call `npm run generate:synthetic` on Windows.

Resolve Python like `scripts/install-all.sh`: `PYTHON` if executable, else `$repo/.venv/Scripts/python.exe`, else `$repo/.venv/bin/python`. **Do not set `PYTHONPATH`.** Rely on `pip install -e apps/api[dev]`.

```text
"$python_bin" -m app.devtools.synthetic_dataset \
  --output "$scratch/photos" --count "$COUNT" --width 3000 --height 2000 --quality 88
```

Refuse pass if width/height are the 160×120 defaults. Generate **on the runner**.

Rust-free test: when a fake tree has both `Scripts/python.exe` and `bin/python`, **Scripts wins**.

### 6.3 Launch

**Windows (`windows-latest`):**

- Silent current-user `/S` of the just-built `bundle/nsis/*.exe`. Installed exe is the Cargo package binary `framepilot-desktop.exe` under `%LOCALAPPDATA%\FramePilot\` (`productName` is `FramePilot`; `bundle.windows.nsis.installMode` is `currentUser`; #144). Fail if that exe is missing after `/S`. Do not treat a `FramePilot.exe` miss as skip.
- Fail if WebView2 runtime is missing. Do not skip.
- `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--disable-gpu --use-gl=swiftshader --disable-features=CalculateNativeWinOcclusion` on the **GUI** process only.
- Inherit QA env in-process. `WindowStyle Normal`. Kill leftover `framepilot-desktop` / `framepilot-api` at start (single-instance).
- After `done`: GUI quit, then `uninstall.exe /S`. Do not upload `%APPDATA%\FramePilot`.

**macOS (`macos-latest`):**

- `hdiutil attach -nobrowse` the just-built DMG; copy `FramePilot.app` to `{prefix}/app/FramePilot.app`; `xattr -cr`.
- Launch **`Contents/MacOS/FramePilot` as a child with env**. Live `#177` smoke uses `open "$app_copy"` **without** `--env`; copying that would drop `FRAMEPILOT_DESKTOP_QA` and fail closed (no QA global). Do **not** call `macos-dmg-gui-smoke.sh`.
- Port discovery: `lsof` LISTEN of `framepilot-api` on `127.0.0.1`, else argv `--port`. Never hardcode 8000/6300. Never trust uvicorn “running on …:8000” in sidecar.log. Ready-line is **stdout to Tauri**.
- Quit GUI after `done`; `hdiutil detach`.

**Both:**

- `FRAMEPILOT_DATA_DIR={prefix}/data`.
- Unset proxy; `curl --noproxy '*'` for health.
- Window title `FramePilot` best-effort; title failure is not pass by itself.
- Missing `idle` on Darwin/Windows → **exit 1**, not 2.

### 6.4 Scratch lifecycle

**Start of every invocation:** `rm -rf` `photos`, `project`, `data`, `evidence`; mkdir siblings; `{prefix}/project` is empty; `chmod 700` prefix. Optionally keep `{prefix}/app`.

**EXIT trap (including fail/skip):** write `result.json` if needed; copy `result.json` **and** a redacted sidecar.log excerpt to **`$RUNNER_TEMP/desktop-500-gui/{mode}-{os}/`**; **then** wipe photos/project/data/evidence (not `$RUNNER_TEMP`). Never upload from the wiped prefix.

### 6.5 RSS

Sample every 2s into `rss.jsonl`.

Join: for each milestone timestamp `T`, take the **last** sample with `t <= T` and `T - t <= 5s`. Else fail.

MB formulas (**do not** reuse `performance_smoke.py` `_max_rss_mb`):

| Source | MB |
| ------ | -- |
| Darwin/Linux `ps -o rss=` | kilobytes / 1024 |
| Windows `WorkingSet64` | bytes / 1024 / 1024 |

Windows UI = `framepilot-desktop.exe` + child `msedgewebview2.exe` (PID tree; if unattributed, sum host-wide and flag). macOS UI = `FramePilot` + WebKit children. Sidecar RSS missing, process death, sample `0`, or join miss → **fail**.

Record four points (idle, import-complete, process-complete, first-preview) **and** peak. **No product MB cap.** Do not advertise a 16× factor as DoD.

Fixture: fake Darwin `ps` `2048` → `2.00` MB.

### 6.6 Originals

Before launch, for every file under `{prefix}/photos`: `st_size`, `st_mtime` (`st_mtime_ns` when available), SHA-256. After `done`, re-check. POSIX: `{project}/originals` must not share inode with sources.

### 6.7 Timeouts

| Scope | Value |
| ----- | ----- |
| Matrix `build` job `timeout-minutes` | **180** |
| Probe step | **10** |
| 500 step | Windows **45**, macOS **40** |
| Sidecar `GET /health` | 60 s |
| `idle` after health | 90 s then exit 1 |
| Import poll (500) | 25 min |
| Process poll | 10 min |
| Preview `<img>` | 60 s |

Do not put waits inside `Build Tauri installer` (`test-release-checks.sh` forbids `exit 1` there). Installer **upload stays before** GUI so a hang does not lose NSIS/DMG artifacts.

Disk: photo scratch budget ~2 GB; likely OOS cause is `target` / PyInstaller / `node_modules`, not JPEGs. `trap` deletes photos.
